# 🌦️ Weather Forecast Web Application

A web application built using **Python and Django** that retrieves current weather information for cities using the OpenWeather API.

### 🚀 Live Demo

[**View Live Application →**](https://weather-forecast-app-offq.onrender.com/)

### ✨ Features
- Search weather information by city name.
- Fetch current weather data using API integration.
- Display weather information through a user-friendly interface.
- Handle API requests and invalid city inputs.

### 🛠️ Tech Stack
- **Backend:** Python, Django
- **Frontend:** HTML, CSS, JavaScript
- **API:** OpenWeather API

### 💻 Run Locally

```bash
git clone https://github.com/zombie-132/weather-forecast-app.git
cd weather-forecast-app
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
